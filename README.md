# Daily Canteen — сайт-визитка

Статический сайт ТОО «Daily Canteen» (БИН 200140012296), бренд Rabbit Canteen.
Основная цель — подтверждение компании в Meta Business Manager для WhatsApp Business API.

Языки: русский (корень), казахский (`kk/`), английский (`en/`).

- `index.html`, `kk/index.html`, `en/index.html` — главная (о компании, услуги, реквизиты, контакты, карта)
- `privacy.html`, `kk/privacy.html`, `en/privacy.html` — политика конфиденциальности (нужна для WABA)
- `assets/` — стили, логотип, иллюстрации из презентации

Сборка не нужна: это обычный HTML. Можно разместить на GitHub Pages, Netlify, Cloudflare Pages или любом хостинге.

## Что проверить для Meta

Данные на сайте должны в точности совпадать с данными в Business Manager и в документах:
название юрлица, адрес, телефон, домен. Подтверждение домена — мета-тег в `<head>` каждой страницы
(место отмечено комментарием) или TXT-запись в DNS.
